# SQL Warehouse Insights

An end-to-end **SQL Server Data Warehouse project** focused on building a scalable data architecture, developing ETL workflows, transforming raw data, and generating business-ready insights.

## Key Features

- Data extraction and loading from CRM and ERP sources
- ETL pipeline development using SQL
- Data cleansing and transformation
- Medallion Architecture (Bronze, Silver, Gold)
- Fact and Dimension modeling
- Star Schema implementation
- Data quality checks and validation
- Business-focused analytical queries

## Architecture

The project follows the **Medallion Architecture**:

- **Bronze:** Stores raw source data.
- **Silver:** Cleans, standardizes, and transforms data.
- **Gold:** Provides business-ready analytical views.

## Tools & Technologies

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL
- Git & GitHub

## Project Goal

To design and implement a complete SQL Data Warehouse that transforms raw CRM and ERP data into reliable, structured, and meaningful business insights.
